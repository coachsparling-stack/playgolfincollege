# Instructions for Claude: playgolfincollege.com

This repo is the live website for Play Golf In College (PGIC), Brad "Coach Spar" Sparling.
Pushing to `main` publishes the site automatically through Vercel (playgolfincollege.com and www).

## Ground rules
- **Never push to `main` without Brad's OK.** For a change, push to a branch first. Vercel builds
  a private preview link for every branch; give Brad that link and wait for him to approve.
  Merging the branch into `main` publishes it.
- One chat at a time should edit the site. Always `git pull` before starting so you build on the latest version.
- Brad can't unzip files. Send changed files one by one, never as a zip.
- Brad works alone, so keep the site simple. It's meant to sell and to bring in applications.

## How the pages are built
- `index.html` (the homepage) is edited **by hand**.
- Every other page is generated by `_source/gen.py`. **Edit gen.py, not the generated .html files.**
  Otherwise the next build will overwrite your change.
- Build from the repo root with `python3 _source/gen.py`. It does three things:
  - It rewrites about, advisory, apply, apply-step2, books, elite, foundations, international, pay,
    recruiting, teaching and testimonials.
  - It copies the menu (`NAV` in gen.py) into index.html.
  - It reuses the homepage's `<style>` CSS, plus the `EXTRA` CSS in gen.py.
- `_source/testimonials_section.html` holds the testimonial quotes that gen.py reads.
- Images live in `img/`. The hero photo for each page is set in `HERO_IMG` in gen.py.
- After building, run `git diff --stat` and check that only the pages you expected changed.
- `_source/` and this file are excluded from the site by `.vercelignore`.

## Key helpers in gen.py
- `page(fname, title, eyebrow, h1, sub, price, program_html, pay_html, tab1)`: one service page.
- `sec(h2, body, eyebrow)` is a page section.
- `items(rows)`, `check(rows)` and `rhythm(rows)` are list styles.
- `NAV` is the top menu, including the Services dropdown. `FOOT` is the footer.
