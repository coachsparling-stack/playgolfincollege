# Play Golf In College

Static website for playgolfincollege.com. Plain HTML, no build step.

- Pages: index, about, elite, advisory, recruiting, teaching, foundations, books, pay, apply, apply-step2, testimonials
- Images in `img/`
- Forms post to Formspree; payments go to PayPal payment links on pay.html
- Hosted on Vercel; every push to `main` republishes automatically
